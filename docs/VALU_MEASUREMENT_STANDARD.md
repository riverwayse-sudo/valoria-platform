# VALU Measurement Standard

VALU is a measurement instrument, not merely a questionnaire.

## Required registry per item

- Question ID
- VALU version
- PRIME dimension
- Skill
- Construct
- Response scale
- Scoring rule
- Weight
- Reverse-scoring flag
- Validation rationale
- Active/inactive status

## Score integrity

Every completed assessment stores scoring_version, rubric_version and assessment_version. Historical results must remain reproducible under the version used at completion.

## Validation programme

Before claiming institutional measurement validity, Valoria should establish item analysis, internal consistency, response-pattern analysis, test-retest reliability, construct/factor evidence and criterion/longitudinal validity. These are evidence requirements, not UI requirements.
